## 1. Architecture (runtime)

```text
[Consumer browser]
    → Cloudflare DNS (grey cloud until Let's Encrypt OK on NPM)
        → Nginx Proxy Manager (:443)
            → what2eat-web:3000  (stack what2eat, portainer_network)
                → PostgreSQL what2eat @ 101.132.156.250:5432  (external; not on VPS)
                → HTTPS server-to-server → places-agent:3000
                       Bearer PLACES_AGENT_CALLER_KEY
                       /v1/search_restaurants, /v1/get_place_details, …
                       POST /v1/chat (MVP-3)
                → Resend (password reset email)
Browser localStorage ← chat transcripts only (never DB, never server persist)
```

### Process model

| Item | Choice |
| --- | --- |
| Containers in stack | **1** — `what2eat-web` |
| In-process | Next App Router pages + `/api/*` BFF Route Handlers |
| **Not** in this image | Map vendors, MCP, agent Quanzil tool loop, places-agent admin |
| Entry | Next **standalone** after `next build` — **`next start`** or `node server.js` from standalone output (**not** `server.ts` / MCP) |
| Chat LLM | **places-agent** `POST /v1/chat` via BFF ([ADR-020](../../workspace-specs/adr/ADR-020-http-only-chat-and-enrich.md)) — **no** `OPENAI_*` on this stack |

### Public vs private

| Surface | Public via NPM? | Auth |
| --- | --- | --- |
| Consumer pages `/`, `/register`, `/login`, `/decide`, … | Yes | Session cookie on signed-in routes |
| BFF `/api/*` | Yes (same origin) | Session + CSRF on mutations |
| Host bind `3004→3000` | Debug only | Do not publish as primary path |
| Postgres `what2eat` on Aliyun | **No** public bind | `DATABASE_URL` in Portainer only |
| `PLACES_AGENT_CALLER_KEY` | **Never** browser / git | Portainer env only |
| Map keys (`AMAP_*`, `GOOGLE_*`, …) | **Forbidden** on this stack | places-agent only |

### Persistence

| Data | Store | Volume |
| --- | --- | --- |
| Users, tastes, saved places, decision history | **PostgreSQL** + Prisma ([ADR-023](../../workspace-specs/adr/ADR-023-what2eat-postgres-prisma.md)) | Prod: **`101.132.156.250:5432/what2eat`**. Local: **`localhost:5435`** via `docker-compose.dev.yml` |
| Prod `DATABASE_URL` | `postgresql://…@101.132.156.250:5432/what2eat` | Portainer secret |
| Local `DATABASE_URL` | `postgresql://what2eat:what2eat@localhost:5435/what2eat` | Dev compose |
| Chat transcripts | Browser **localStorage** only | **No volume** |
| Profile photo uploads (if implemented) | Volume or object storage | TBD in app spec; if under `public/` post-boot, follow release-bot ADR-001 (API rewrite + volume) |

Migrate on **boot** (`prisma migrate deploy` in entrypoint). Tests use **`TEST_DATABASE_URL`** (e.g. `what2eat_test`) — never production credentials.

## 4. Compose contract

**Path (when landed):** `docker-compose.prod.yml` at app-repo root.

Requirements:

- Application service uses **`image:` only** — **no** `build:` on 野草云3  
- `networks.default.external: true` + `name: portainer_network`  
- Stable `container_name: what2eat-web`  
- **No** app data volume — Postgres is external ([ADR-023](../../workspace-specs/adr/ADR-023-what2eat-postgres-prisma.md))  
- `DATABASE_URL` required (PostgreSQL)  
- `PORT=3000`, `HOSTNAME=0.0.0.0`, `NODE_ENV=production`

**Local dev only:** `docker-compose.dev.yml` at repo root — Postgres on host **`5435`** (not deployed on 野草云3).

### Proposed `docker-compose.prod.yml` (land in app repo)

Host port **`3004` is proposed** — confirm on node before deploy.

```yaml
name: what2eat

services:
  web:
    image: ghcr.io/ethanhuangcst/what2eat.food/web:${IMAGE_TAG:-latest}
    container_name: what2eat-web
    restart: unless-stopped
    ports:
      - "3004:3000"
    environment:
      NODE_ENV: production
      APP_NAME: what2eat
      APP_ENV: production
      PORT: "3000"
      HOSTNAME: "0.0.0.0"
      DATABASE_URL: ${DATABASE_URL:?set DATABASE_URL}
      SESSION_SECRET: ${SESSION_SECRET:?set SESSION_SECRET}
      PUBLIC_BASE_URL: ${PUBLIC_BASE_URL:-https://what2eat.food}
      APP_URL: ${APP_URL:-https://what2eat.food}
      PLACES_AGENT_BASE_URL: ${PLACES_AGENT_BASE_URL:-https://places.agent-mate.ai}
      PLACES_AGENT_CALLER_KEY: ${PLACES_AGENT_CALLER_KEY:?set PLACES_AGENT_CALLER_KEY}
      PLACES_AGENT_TIMEOUT_MS: ${PLACES_AGENT_TIMEOUT_MS:-25000}
      W2E_DEFAULT_PROVIDERS: ${W2E_DEFAULT_PROVIDERS:-["GOOGLE_MAPS"]}
      W2E_ENRICH_TRIPADVISOR: ${W2E_ENRICH_TRIPADVISOR:-true}
      FEATURE_EMAIL: ${FEATURE_EMAIL:-true}
      RESEND_API_KEY: ${RESEND_API_KEY:-}
      RESEND_HOST: ${RESEND_HOST:-api.resend.com}
      RESEND_BASE_URL: ${RESEND_BASE_URL:-https://api.resend.com}
      RESEND_FROM_EMAIL: ${RESEND_FROM_EMAIL:-}
    networks:
      - default

networks:
  default:
    external: true
    name: portainer_network
```

**Internal agent URL (optional optimization):** On `portainer_network`, BFF may use `http://places-agent:3000` if places-agent stack is up and caller key is valid. Public smoke still uses `https://places.agent-mate.ai`. Pick one base URL in Portainer and keep it stable.
